# Georgia Tech Photography Club Website

A modern, gallery-focused website for Georgia Tech Photography Club. The site is designed to showcase student photography, promote upcoming events, introduce the club to new members, and provide a foundation that can grow over time.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Motion
- Lucide React

## Current Features

- Responsive navigation and footer
- Full-screen photography hero
- Featured photo credits
- Gallery, Events, About, and Join routes
- Reusable content types and data files
- Accessible motion preferences
- Responsive layouts for desktop and mobile

## Planned Features

- Masonry photo gallery
- Photo filtering by category
- Full-screen photo lightbox
- Photographer profiles and credits
- Upcoming event cards and calendar
- Event archive and recap galleries
- Executive board profiles
- Member photo submission workflow
- CMS integration
